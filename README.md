# Lisajo – Rent Ledger

Tenant ledger, receipts, balances and rent reminders (rent due on the 10th).

## Run
```
npm install
npm run dev
```

## Status
MVP front end only (React + Vite). Data is in memory; SMS sending is simulated.

## Next
Backend REST API + database, SMS provider (e.g. Africa's Talking), scheduled reminders on the 10th.
